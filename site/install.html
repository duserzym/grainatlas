Getting started

Install GrainAtlas

Desktop builds are available for macOS on Apple silicon and Windows x64.

Install the macOS app

  1. Download grainatlas_0.1.6_aarch64.dmg from GitHub Releases.
  2. Open the disk image and drag GrainAtlas to Applications.
  3. Open GrainAtlas from Applications.

Allow the first launch

The app is not notarized, so macOS blocks its first launch.

  1. Try opening the app once, then dismiss the warning.
  2. On macOS 15 and later, open System Settings → Privacy & Security.
  3. Choose Open Anyway for GrainAtlas and confirm the launch.

On older macOS, Control-click the app in Applications and choose Open.

Install on Windows

  1. Download grainatlas_<version>_x64-setup.exe from the latest GitHub release.
  2. Run the setup file. If SmartScreen blocks it, choose More info, then Run anyway. The installer is unsigned.
  3. Open GrainAtlas from the Start menu.

It installs for the current user without admin rights and downloads WebView2 if it is missing. Later versions arrive through the in-app update check. If you use a portable grainatlas.exe, run the setup file once to receive in-app updates.

Keep it up to date

Click the version chip at the bottom right, or go to Settings → Updates. Use Check now, choose Stable or Beta, and choose whether to download updates automatically. A downloaded update waits for Restart to update.

Use a browser build

The browser version is a static build. It uses the same Rust core through WebAssembly. A source checkout needs Rust, Node with pnpm, and an upblab checkout beside grainatlas for @lab/bridge.

make setup
make full
make ui-build
python3 -m http.server -d ui/dist 8000

Open the address printed by the server. Browser Save downloads a .gaproj; reopen the image package when returning to a project. The browser build links to releases rather than installing desktop updates.

Use UPb Lab

UPb Lab connects GrainAtlas to the rest of the workflow. Hosted copies use the shell’s sign-in, theme and updates. UPb Lab can also open the installed standalone app with a one-time sign-in code.

Build and development details are in Developing GrainAtlas.
