From SEM tiles to laser-ready print sheets

grainatlas stitches CL, BSE and SE grain-mount images, finds every grain, lets you make the final call by hand, places LA-ICP-MS spots and prints every grain once at one scale. It runs as a web page or a desktop app, and your images never leave your computer.

Get started See the workflow

Six steps, one window

The screenshots are of the bundled test fixture: one 3 × 2 tile area of a Hitachi TM4000 CL package at 150×.

1

Open a package

Drop a folder on the window. grainatlas reads a TM4000 Zigzag package, a single area folder, any folder of images with a positions.csv, or loose images with a scale you type once. Several packages or saved projects open as tabs.

2

Stitch and tone

Tiles are placed from the stage positions, every overlap is refined, and the whole area is solved at once. Gain, offset, beam-exposure steps and background are corrected in one solve. Auto sets the tone from the histogram, and every control re-renders the mosaic live.

3

Find the grains

One click outlines every grain, including CL-dark zircons. Epoxy bubbles, tile-seam slivers, exposure blocks and specks are flagged with a reason, never silently dropped. Grains carry no numbers; spots do.

4

Make the final call by hand

Delete what is not a grain. Redraw an outline with a lasso that snaps to grain edges, freehand or click by click; ⇧ adds and ⌥ cuts. Touch up an outline with a brush sized in µm. Hand-drawn grains survive Find again, and every edit undoes.

  • D Delete
  • O Outline
  • B Brush
  • G +Grain
  • K Split
5

Place spots

Click a grain to place a laser spot. Spots are named sample_n, and n counts up across samples within a session, like an instrument run number; type a start number at any time, or restart at 1 for each sample. Select several spots to change their size, renumber them or rename them at once. Export the spots as CSV or GeoJSON, or send them to laicpmsdb.

6

Print every grain once

Tabloid sheets at one scale (1 mm = 8 µm by default), cut straight out of the mosaic as bands, sample by sample. Each sheet has the instrument header, a mount map and the laser spot sizes at print scale. A registration file maps every band on paper back to the mosaic.

What's inside

One core, two shells

A Rust core runs in the browser (wasm in a Web Worker) and natively in a Tauri 2 desktop app, and both builds hash the fixture mosaic identically.

Stitching that checks itself

Stage prior, phase correlation, a Lucas-Kanade refinement and a global least-squares solve, with residuals drawn on the mosaic.

Photometric correction

One joint solve for per-tile gain and offset, beam-exposure steps and background, then seam or multiband blending.

Segmentation you can overrule

Bright and CL-dark grains, flagged artifacts, GrabCut refinement, and a live-wire lasso and brush for the hard ones.

Spots, lines, rasters

Placed with the mouse or trackpad alone, with UUIDv7 ids, presets in µm and names that follow your lab's numbering.

Paper and the laser

Print sheets with a registration sidecar, atlas bundles for laicpmsdb, results on the spots, and a fiducial fit to the laser stage.

Install

Build from source on macOS, Linux or Windows. You need Rust (stable), Node with pnpm, and a checkout of upbstudio next to grainatlas for the @lab/bridge package.

git clone https://github.com/duserzym/grainatlas
cd grainatlas
make setup         # Rust + wasm target, wasm-bindgen, UI dependencies, Playwright
make ui-dev        # web app on http://localhost:5174
make desktop-dev   # desktop app (Tauri 2)

For batch work, the command line stitches a package and writes print sheets in one go:

cargo run --release -p grainatlas-cli -- stitch <package> \
  --out <name>.grainatlas --auto --polarity both --print tabloid

Supported now: Hitachi TM4000 Zigzag packages, single area folders, image folders with positions.csv, and loose images with a typed scale.
