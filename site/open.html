Open screen

Open images

Read the original images and their scale before stitching.

  1. Drop a folder or image files on the window, or use Choose folder… or Choose images….
  2. For loose images, enter µm per pixel or the field width. Choose whether the images are separate areas or one grid.
  3. Check the areas, then continue to Stitch and tone.

Supported inputs

InputWhat to open
TM4000 Zigzag packageThe folder containing the .zag file and one subfolder per area.
Single TM4000 areaAn area folder with its .ini, tiles and .txt sidecars. Scale and stage positions come from the sidecars.
Images with positionsA folder with positions.csv: file,x_um,y_um,pixel_size_nm.
Loose imagesJPEG, PNG, TIFF or BMP images, with a scale you enter once.

Return to a project

Choose an entry in Recent projects. If its folder has moved or is unavailable, locate it again. In a browser, images are not kept between visits: open the package again, then use Project file to load the saved record.

A .gaproj holds parameters, grain outlines, spots and labels, without pixels. On desktop, opening it reads the images from the recorded path and renders saved placements without stitching again.

Work in tabs

Several packages or saved projects can stay open as tabs. Use ⌘T for a new tab, ⌘W to close, and Ctrl + Tab to switch. A dot marks unsaved changes; closing asks before discarding them. Use Ctrl instead of ⌘ where applicable.

Packages are read locally. Publishing an atlas to UPbDB is a separate, optional action.
